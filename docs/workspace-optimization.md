# 知识空间体验优化（2026-11-16）

本轮集中优化首页、资料管理、检索到提问的流程和前端状态处理，沿用现有绿色主题及高对比度阅读规则。

## 已完成

- 首页展示当前知识库的可检索资料数、知识片段数、最近三份可用资料，提供浏览、检索和上传入口。
- 文档页增加资料统计、全部/可检索/处理中/需处理筛选，支持最近上传、名称、文件大小排序，以及手动刷新。搜索忽略首尾空格，空结果可以一键清除筛选。
- 上传提供拖入反馈、当前文件和批次进度；不支持、超限或空文件会跳过，继续处理其他文件。权限失效时停止批次。进度按文件数计算，不表示单文件传输字节进度。
- 语义检索结果可以把原问题带入新对话草稿，用户点击发送后才调用对话服务。
- 聊天支持复制回答；失败问题可以恢复至输入框编辑，保留原有消息。用户上翻时停止自动跟随，点击「回到最新回答」后恢复。
- 资料和历史对话的加载使用独立版本标记，忽略切换知识库、开启新对话后的迟到结果；来源详情也会忽略失效响应。
- 增加知识库加载状态、错误提示和重试入口，避免把请求失败显示成空资料。
- 有资料处理中时才每四秒刷新；页面隐藏时跳过，窗口重新获得焦点、进入文档页或点击刷新时更新。并发刷新会合并为后续一次更新。
- 设置与数据查询组件改为按需加载。

布局样式集中在 `frontend/src/workspace.css`，在公共主题之后加载。
